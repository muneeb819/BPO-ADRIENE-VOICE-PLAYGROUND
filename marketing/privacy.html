Where your data lives

The platform is self-hosted. Transcripts, events and agent configuration are stored in your own database. Provider credentials are read from the server environment and are never returned to the browser.

Audio and retention

Call audio is processed by your configured speech provider and is retained for the period you set. Telephony is disabled by default, so no live calls are placed unless an operator enables them.

Consent

  • Transfers to a human require explicit consent from the caller.
  • Consent state is stored with the session so it can be reviewed later.
  • Analytics are computed from stored events, never from estimates.
