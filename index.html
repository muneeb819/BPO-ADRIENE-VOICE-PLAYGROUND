Error handling

Every failure returns a safe JSON envelope with a useful status code.

400Validation — name, instructions, ranges, script shape
404Missing agent, session, case, provider or version
409Archived agent or inactive session conflicts
429Rate limit — 240 API requests / minute / client
500Internal error — generic message, never a stack trace
