  • • Agent name ≥ 2 chars, instructions ≥ 10 chars, speaking rate 50–200 — enforced server-side.
  • • Turn content capped at 2,000 chars; test scripts require 1–50 valid user steps.
  • • Safe error envelope { error: string } with 4xx/5xx — no stack traces leaked.
  • • Per-client local rate limit: —.
  • • Session writes are scoped by opaque session ID; invalid IDs return 404, never cross-session data.
  • • Request bodies are size-capped; uploads are limited to 8 MB.

Authentication & Access Control

Local-only by default. Before exposing beyond localhost, authentication is required.

Current mode: —

To require a bearer token for /api/*:

# .env (server process only)
AUTH_ENABLED=true
AUTH_SECRET=<32+ random characters>

# Then every /api/* request must carry:
Authorization: Bearer <AUTH_SECRET>

# Do not ship the secret to the browser. For remote access,
# terminate auth at a local reverse proxy.
⚠ Dashboard must not be exposed beyond localhost without auth.

Session-scoped authorization

Sessions are addressed by opaque IDs; all writes are server-validated. Invalid session IDs return 404. This build uses HTTP polling, not WebSocket, so there is no socket handshake to authorize — the session ID is the boundary.

Retention Controls & Deletion

Sensitive data is not retained indefinitely by default.

—

Auto-delete is disabled unless explicitly enabled. “Delete Artifacts” removes sessions, mock telephony logs and test runs from SQLite.

Migrations, Backups, Health & Shutdown

SQLite is embedded — no Docker, Postgres or external migration toolchain.

Schema migrations

The schema is created and extended idempotently at startup. There is no ORM migration step.

python server.py
Backup & restore

Stop the server first, then copy the SQLite file.

Copy-Item data\adriene.db data\adriene-backup.db
Copy-Item data\adriene-backup.db data\adriene.db
Health

GET /api/health returns ok + database + capability flags.

Graceful shutdown

Press Ctrl+C in the server console. In-flight responses drain; SQLite commits are immediate and the DB closes cleanly.
