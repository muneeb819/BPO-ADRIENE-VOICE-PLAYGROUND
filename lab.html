Provider Notes & Fallback Policy

  • • Local TTS only where a runtime is installed — otherwise fall back to Browser Speech Synthesis (always available).
  • • Missing credentials produce actionable errors, never silent failures.
  • • Fallback only when explicitly configured and safe — e.g., Deepgram TTS → Browser TTS.
  • • At least one STT + one TTS path must pass before voice is marked production-ready.
  • • Keys stay backend-only — not in logs, browser storage or source control.
