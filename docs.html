SQLite & Local Operations

Embedded database, no Docker Compose, no Postgres, no ORM migration step.

Schema & migrations

Tables are created and extended idempotently when the server starts. Existing sessions and agents survive restarts.

python server.py
# data/adriene.db is created on first run
Backup & restore

Stop the server, copy the database file, then restart. SQLite WAL files are checkpointed on clean shutdown.

Copy-Item data\adriene.db data\adriene-backup.db
# restore
Copy-Item data\adriene-backup.db data\adriene.db
Diagnostics

/api/health reports DB, storage, uptime and capability flags. Per-session events are in Analytics → Inspect.

SQLite stdlib HTTP no CORS wildcard
Dependency pinning

Python 3.12 standard library only. Provider calls use urllib; persistence uses sqlite3.

no pip runtime deps no npm

Known Limitations & Environment Requirements

  • • Windows 11 PowerShell workflow; Python 3.12 is required. No Node/Postgres at runtime.
  • • Deepgram TTS/STT needs network access and a valid backend key.
  • • Microphone permission requires HTTPS or localhost; failures degrade to text.
  • • Real telephony is pending VICIdial test environment + legal consent.
  • • No Redis/K8s/Docker — intentionally omitted for a local-first build.
  • • Browser TTS voices vary by OS; Aura is server-side when configured.
